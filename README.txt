# AI WeerHub Pro V46 — PWA

Deze map is een installeerbare Progressive Web App (PWA).

## Online zetten
Zet de volledige inhoud van deze map op een HTTPS-webserver.
De startpagina is `index.html`.

## Samsung / Android
Open de HTTPS-site in Chrome en kies:
**⋮ → App installeren** of **Toevoegen aan startscherm**.

Daarna staat AI WeerHub als app op het startscherm.

## Belangrijk
De live weer- en modelgegevens blijven rechtstreeks via de bestaande API-koppelingen worden opgehaald.
